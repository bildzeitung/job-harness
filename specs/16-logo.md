# Spec 16 — Job Harness Logo

Important: **Use the AskUserQuestion tool if you have uncertainty about the tasks; confidence level >=95%.** Decisions already made by the user are listed below — do not re-ask them.

## Goal

The application suite needs a logo.

## Design

The logo should be the head of a cheerful goose, illustrated with plain simple lines and basic colouring.

## Constraints

- logo should be have an ASCII version and a web version
- logo should be square or circular -- usable as a patch, for example
- logo should not be overly large (in the case of a text logo)
