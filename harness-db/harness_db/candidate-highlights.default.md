# Candidate Highlights

Quick-reference profile every `job-seeker` searcher reads at startup (via
`$JOB_DATA_ROOT/candidate-highlights.md`) instead of loading the full resume.
**This is your file to edit** — it ships as a generic starter; replace the
examples below with your own highlights in one place.

## Key Highlights

- <Role / seniority>, <years> years experience
- <Most notable employer or achievement>
- Stack: <your primary languages, clouds, and tools>
- Located: <city, region, country> — **must be fully remote**
- Expertise: <your core domains, e.g. cloud infrastructure, distributed systems>
- Target roles: see `target-roles.md`
- Certifications: <list any vendor/industry certs, or note "none">

## How to Use This File

Searchers read it from your job-data root:

```bash
cat "$JOB_DATA_ROOT/candidate-highlights.md"
```

Do not hardcode candidate highlights in individual agent files — edit this file
instead.
