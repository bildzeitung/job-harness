# Memory Index

- [Ashby Job Posting Access](reference_ashby_api.md) — Ashby job descriptions are reachable via the public job-board API
- [Greenhouse ATS Job Posting Access](reference_greenhouse_ats.md) — Greenhouse job pages embed the description in a JSON `content` field; double-unescape
- [Rippling ATS Job Posting Access](reference_rippling_ats.md) — Rippling job pages embed the full description in `__NEXT_DATA__` JSON
- [Dayforce ATS Job Posting Access](reference_dayforce_ats.md) — Dayforce job pages embed full content in `__NEXT_DATA__`, at pageProps.jobData.jobPostingContent
